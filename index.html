☁️ Cloud Sync (GitHub Gist)

How to sync Mac, iPhone & iPad automatically:
1. On GitHub.com, go to Settings → Developer settings → Personal access tokens → Tokens (classic) and generate a token with only the gist checkbox selected.
2. Paste the token below and tap Save & Connect (leave Gist ID blank on your first device to create one automatically).
3. Copy the Gist ID to your other devices and enter the token separately on each one. The token is saved in this browser so it survives reloads; it is not shared with other devices.
Security: The token is stored in this browser's local storage, which is not encrypted. Avoid saving it on shared devices or browser profiles.
Clearing the token and saving switches this browser to Local mode and removes its saved token and Gist ID. It does not delete the Gist or disconnect other devices.
