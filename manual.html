User guide · Current app release

Keep the schedule clear, balanced, and easy to share.

Use this guide to set up your rotation, update assignments, track confirmations, and make backups. The manual matches the v50 interface. The app saves changes in this browser automatically; cloud sync is optional.

🚀 Quick start

For a new or reset schedule, begin with these steps before sending assignments:

1Review the roster

Add approved conductors, correct their names, and arrange them in rotation order.

2Set the rotation anchor

In Approved Conductors, set Start #1 to the meeting date that should begin with the first person in the roster.

3Check schedule details

Confirm the next assignments, meeting time, and location, then add known unavailable dates before sharing.

Changing the rotation start date or roster order can change future automatic assignments. Past dates are protected by default; review the upcoming schedule after making either change.

🗓️ Home screen and calendar

  • Up Next shows the next active meeting date, assigned conductor, time, location, and any reminder status. Use Quick Replace to choose a different conductor for that date, or choose the automatic assignment to restore the rotation.
  • Calendar / Year List switches between the month grid and a list of dates for the selected year. Use the year selector to change years; in Calendar view, use Prev, Next, or Today to move between months.
  • The schedule includes the second and fourth Saturday of each month, plus a fifth Saturday when one occurs. A canceled meeting is removed from active assignments.
  • Use the conductor dropdown in a calendar date cell to change that date’s assignment. Use the date controls to cancel or restore a meeting, or open its time/location override.
  • On a narrow screen, Schedule actions and Conductor list are collapsible to keep the calendar near the top.
What does the assignment label mean?
  • Auto means the conductor comes from the current roster rotation.
  • Override means a conductor was selected specifically for that date.
  • Reassigned means the automatic rotation skipped one or more conductors marked unavailable for that date.
  • Locked indicates a past assignment protected from rotation changes. Use Past Locked in the roster panel to change the history-lock setting.

🔁 Rotation and date assignments

Roster order and automatic assignments

The roster order defines who is next in the rotation. Start #1 sets the anchor date for the first roster position. If you change the order or anchor, inspect the displayed assignments before sending an updated schedule.

Change one date without changing the rotation

  1. In the calendar, use the conductor selector for the meeting date, or use Quick Replace for the Up Next date.
  2. Select the replacement conductor. This creates a date-specific override; the rest of the rotation remains in place.
  3. To undo the override, select the automatic option (shown as Auto (name) in Quick Replace).

Mark unavailable dates

Open a conductor’s edit button in the roster. Add a vacation date range, a single unavailable date, or use the upcoming-Saturday checkboxes. Save the changes. If that conductor is due on a marked date, the rotation skips them and uses the next available person, if one is available.

Cancel or restore a meeting

Use the date’s cancel control, select a preset reason or enter your own, then confirm. The rotation pauses for that canceled meeting and resumes at the next scheduled meeting date. Use the restore control on that date to put it back.

Meeting time and location

Choose Schedule actions → Sync & Tools → Time & Location to set defaults. The same dialog lets you add a custom time or location to a specific upcoming date. Leave a per-date field blank to use the default; remove a listed override to clear it.

Past Locked is enabled by default so normal roster and rotation edits do not rewrite recorded past assignments. Unlocking past dates allows the live rotation to affect historical dates.

👥 Approved Conductors

  • + Add Conductor adds a name and optional mobile number and email. The new conductor is appended to the roster.
  • Use the roster’s Edit button to change a name or contact details, move the person earlier or later in rotation order, maintain unavailable dates, or remove them.
  • Each conductor’s message icon opens a personal schedule message. Their calendar icon downloads an individual .ics calendar file.
  • Stats opens assignment counts, last-served information, and unavailable-date skips for the selected year.
  • Use Past Locked to toggle protection for historical assignments. Keep it enabled for normal use.
Removing a conductor also removes their saved contact and unavailable-date settings. Their name may still appear in a past assignment that has been locked.

💬 Reminders, status, and sharing

Track assignment follow-up

Use the reminder pill beside a scheduled assignment to cycle its status. The sequence is Assignment sent → Reminder sent → Confirmed → Requested Sub, then it cycles back to Assignment sent. Use the small × on the pill to clear its tag. Statuses are associated with both the date and the currently assigned conductor.

Send Reminder on Up Next opens a ready-to-review message for that conductor and date. The message is not sent automatically; review it and use the phone’s or computer’s Messages, Email, or share interface to send it.

Share one conductor’s schedule

  1. Use the person’s message icon in the roster, or choose Send Reminder on Up Next.
  2. Choose Short Text or Longer Email, then select the timeframe. The dates begin with the next scheduled date.
  3. Review the recipient and edit the message if needed. You can copy it, open Messages or Email, or use the system share sheet.

Share all schedules

Choose Schedule actions → Share All Schedules. Select a timeframe and text or email format. For group text, choose either a single group message or the one-by-one queue, which steps through each conductor. Verify the recipients and message before sharing.

Message templates and status updates
  • Edit the preview directly before sharing. Save as Default keeps the edited wording for future messages of that type; Reset Default restores the built-in wording.
  • Templates support tags such as {firstName}, {fullName}, {dates}, {defaultTime}, and {defaultLocation}. Group messages also support {schedules} and {timeframe}.
  • Messaging or sharing actions can update the assignment’s reminder tag. Check the pill after the external app opens and adjust the status if needed; opening another app does not guarantee that the message was sent.
  • A Requested Sub tag records a request; it does not automatically select a replacement. Use Quick Replace or the date selector to change the assignment.

📤 Calendar and PDF exports

  • Export .ics → Current Month downloads active meeting dates for the displayed month. Full Selected Year exports the selected year.
  • The calendar icon beside an individual conductor downloads their personal .ics schedule. Import the file into a calendar app that supports iCalendar files.
  • Sync & Tools → Print / Save PDF creates a clean schedule sheet starting from the displayed month. Choose 1, 3, 6, or 12 months.
  • Use Print for a printer, Share / Save PDF where supported, or Safari Print on Safari devices. The browser’s print dialog may offer a “Save as PDF” destination.

💾 Save a backup and undo changes

The app automatically saves schedule changes in this browser’s local storage. That is convenient, but it is not a substitute for a backup: clearing browser/site data or changing browsers/devices can remove local-only data.

  1. Choose Sync & Tools → Backup Data (JSON) and keep the downloaded file somewhere safe.
  2. To restore, choose Restore Backup (JSON) and select a backup file created by this app.
  3. Use Undo to reverse a recent schedule change. The app keeps up to 15 undo steps while the app page is open; reloading the page clears that undo history.
A restore replaces the current schedule data with the selected backup. Export a fresh backup first if you may need the current state.

☁️ Optional cloud sync with GitHub Gist

Cloud sync is optional. When it is not configured, your schedule remains in the current browser. When configured, the app syncs schedule data between devices through a non-public GitHub Gist.

  1. Create a GitHub personal access token with only the gist permission needed by the app.
  2. Open Sync & Tools → Cloud Sync, enter the token, and leave the Gist ID blank on the first device. Choose Save & Connect to create the non-public Gist.
  3. Use Copy Sync Info to transfer the token and Gist ID to your other devices. Enter the same credentials there and connect.
  4. Keep Auto-Sync on Changes & App Open enabled for automatic syncing, or use Pull and Push to sync manually.

Changes made offline are saved on the device and queued for upload when the connection returns. The status pill in the app header shows whether the app is local-only, syncing, offline, or connected.

The GitHub token is stored in this browser’s local storage so the app can sync. Treat it like a password: do not send it in an ordinary message or include it in a schedule backup. Anyone with the token may have access to your Gists; revoke the token in GitHub if it is exposed. GitHub’s non-public (“secret”) Gists are not encrypted or fully private: anyone who gets the Gist URL may be able to view its schedule and contact data. Do not store information there that must remain confidential.
Set up another device or disconnect sync

On another device, enter the same token and Gist ID in Cloud Sync settings, then save and connect. If the device already has schedule data, make a JSON backup before connecting.

To disconnect this browser, clear the token field and save. This stops syncing from this device; it does not delete the GitHub Gist or disconnect other devices.

🛠️ Troubleshooting

What you seeWhat to check
A conductor changed in the future schedule Check the roster order, Start #1 date, unavailable dates, and date-specific overrides. Past Locked protects past dates by default.
A date is missing Check whether the meeting was canceled. The calendar schedules the second, fourth, and any fifth Saturday of each month.
Cloud status says Offline Saved Reconnect to Wi-Fi or cellular data and reopen the app. Pending changes should sync when online; you can also open Cloud Sync and use Push.
A message has the wrong date, recipient, time, or location Review the preview and recipient before sharing. Check the assignment, selected timeframe, and default or per-date time/location settings.
The app asks to recover unreadable saved data Do not clear browser/site data or make more schedule changes. The app preserves a recovery copy in the same browser; keep the recovery key and seek help before attempting recovery.

For an app update, connect to the internet and choose Sync & Tools → Check for App Update. Regular updates are also checked automatically when the app is online.
