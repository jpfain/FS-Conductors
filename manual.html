This guide covers how to manage the Field Service Conductor rotation, assignment statuses, cloud sync, and printable/PDF schedules across desktop and mobile devices.

1. Roster, Start Date & Stats

  • Start #1 Date: Set the rotation anchor date (default 2026-11-14) in the roster header to control where the rotation begins.
  • Stats Panel: Click Stats to view last-served dates, days since last assignment, auto-skipped unavailability counts, and yearly totals. Statistics exclude dates prior to the rotation start date (2026-11-14 unless changed).
  • Unavailability & Past Lock: Edit any conductor to add single dates, date ranges, or quick-toggle upcoming Saturdays. Past Saturdays are locked by default unless unlocked via the header toggle.

2. Sharing, Assignment Status & Trades

  • Share All Schedules & Individual Reminders: Send schedules via text, email, or the system share sheet. Sending or tagging an assignment records Assignment sent [date].
  • Cycling Assignment Status: Tap a status pill on a conductor card, calendar cell, or share modal to cycle through Assignment sent [date] → Reminder sent [date] → Confirmed [date] → Requested Sub.
  • Trade Dates & Undo: Use Trade Dates to swap two scheduled meeting dates cleanly, or click Undo to step back recent schedule changes.

3. Print / Save PDF, Calendar Export & Cloud Sync

  • Print / Save PDF: Open Sync & Tools → Print / Save PDF to choose a 1-, 3-, 6-, or 12-month range. Printed and PDF sheets display Date, Conductor, Time & Location, and Assignment Status (including sent dates).
  • Calendar (.ics) Export: Export individual conductor schedules, the current month, or the full selected year from the Export .ics menu or conductor cards.
  • Cloud Sync & Backups: Connect a GitHub Gist token in Cloud Sync to sync across Mac, iPhone, and iPad (offline edits automatically merge with remote changes before uploading), or export/restore JSON backups anytime.
