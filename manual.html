This guide covers conductor assignments, sharing, backups, and optional cloud sync. The app can be used in a browser or installed on a supported device.

1. Schedule Basics

  • Meeting dates: The rotation schedules the second, fourth, and fifth Saturday of each month. Months without a fifth Saturday have no fifth-Saturday assignment.
  • Rotation: Conductors are assigned in roster order, beginning at the Start #1 date. Cancelled meeting dates are skipped and do not advance the rotation.
  • Calendar and Year List: Use the view buttons to switch between a monthly calendar and a selected-year schedule. Change the displayed month or year with the navigation controls.
  • Automatic and manual assignments: A meeting uses the rotation unless an override is selected. Choose Auto to remove an override and return to the rotation. Use Trade Dates to swap two assignments.
  • Cancel or restore a date: Use Cancel on a meeting date to record a cancellation and optional reason. Restore it to put it back in the rotation.

2. Roster, Availability & Stats

  • Add or edit a conductor: Use + Add Conductor to add a name and optional contact details. Select a roster card's edit button to update details, change rotation order, or remove that conductor.
  • Unavailable dates: In a conductor's edit screen, add a single date, a date range, or toggle upcoming meeting Saturdays. Unavailable conductors are skipped for that date without permanently changing the roster order.
  • Past-date lock: Past Saturdays are locked by default to preserve historical assignments. The header toggle controls whether past dates are locked.
  • Stats: Open Stats to review yearly assignment totals and last-served information.
  • Undo: Use Undo after a schedule change to restore a recent state.

3. Sharing & Follow-Ups

  • Share schedules: Use Share All Schedules or a roster card's message button to prepare a text or email schedule. Choose a timeframe and delivery option in the share window.
  • Assignment statuses: Tap a status pill to cycle through Assignment sent, Reminder sent, Confirmed, and Requested Sub. Use Follow-Ups to step through upcoming assignments needing attention.

4. Meeting Details, Print & Calendar Export

  • Time and location: Open Sync & Tools → Time & Location to set defaults or custom details for a specific meeting date.
  • Print / Save PDF: Open Sync & Tools → Print / Save PDF to prepare a 1-, 3-, 6-, or 12-month sheet. Use the print, PDF, or Safari Print option available on your device.
  • Calendar (.ics) export: Use Export .ics for the current month or selected year, or use a roster card's calendar button for an individual conductor's assignments.

5. Local Data, Cloud Sync & Backups

  • Local use and offline access: Schedule data is saved in this browser on this device. After the app has loaded and its files are cached, it can be used offline. Local changes are not shared to other devices unless cloud sync is configured.
  • GitHub Gist sync: After the sync service is configured, open Sync & Tools → Cloud Sync and choose Connect with GitHub. Sign in separately on each device. Create a private Gist on the first device and share only its Gist ID with other devices. The app keeps the GitHub OAuth token on the sync server; the browser stores a revocable session credential in IndexedDB.
  • Offline sync: Changes made offline remain on the device and are queued for upload when connectivity returns, if auto-sync is enabled. Check the cloud status pill for connection or sync status.
  • Backup and restore: Use Sync & Tools → Backup Data (JSON) to save a backup. Use Restore Backup (JSON) to load one. Keep backups somewhere safe, especially before changing devices. Schedule data is migrated from older browser storage to IndexedDB automatically. If saved data cannot be read, use the recovery-copy button before restoring a backup.
  • Sync history: Open Merge History in the Cloud Sync window to review recent reconciliations. Manual Pull asks for confirmation because it replaces the local schedule.
