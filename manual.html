👀 Upcoming Watchlist & Follow-Ups v48

Use the 👀 Watchlist button in the toolbar to view upcoming meeting Saturdays within 7 days that are not yet confirmed, dates with sub requests, or assignments with scheduling conflicts.

  • Follow-Ups Queue: Tap 📬 Follow-Ups on the Up Next banner to jump straight into messaging upcoming conductors who still need confirmation.

⚠️ Conflict-Aware Reassignment & Trading v48

When using Quick Replace or Trade Dates, the app checks whether a candidate is marked unavailable on that date, has a sub request, or is assigned on a nearby Saturday.

🖨️ Print Live Preview & Custom Board Note v48

Open ⚙️ Sync & Tools ▾ → 🖨️ Print / Save PDF to preview your schedule sheet live, add an optional custom board note, and print or save as PDF across 1, 3, 6, or 12 months.

🔒 History Lock, Statuses, Cloud Sync & .ics

  • History Lock & Statuses: Past dates remain locked by default so rotation changes never rewrite history, while reminder/confirmation tags cycle cleanly.
  • GitHub Gist Cloud Sync: Store your GitHub token in Cloud Sync settings (never in a text file) and merge changes across Mac Chrome, iPhone 14, and iPad.
